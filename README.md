# Rlay for Mac

Switch supported conversations between Claude Code, Codex and OpenCode. Answer their Rlay plugin questions in one inbox.

[Download the free Mac preview](https://downloads.tryrlay.com/releases/0.3.8/preview2-arm64/Rlay-Mac.zip) · [Install guide](https://tryrlay.com/compatibility#setup) · [See the demo](https://tryrlay.com/#demo)

No card or license is needed for the preview. Use your installed assistants and existing AI accounts.

## Get started

1. Extract the ZIP and open `Install RlayPilot.command`, then open **RlayPilot** from your user Applications folder.
2. In Setup, choose **In my terminal** and copy your assistant command into a Git project's terminal. Choose an existing provider/model when using OpenCode.
3. Answer a question sent through the Rlay plugin in the Inbox. In a terminal session started through Rlay, press **Ctrl ]** to switch assistants.

Built-in agent approvals stay in the assistant. See the [setup guide](https://tryrlay.com/compatibility#setup) to connect an existing session.

## Tested setup

Apple Silicon on **macOS 26.6.2**. Other Mac configurations have not been verified. Recorded native versions: Claude Code **2.1.294**, Codex **0.162.1**, OpenCode **1.18.18**. Check [compatibility and import limits](https://tryrlay.com/compatibility) before using a different version.

This download is the direct Mac app. Phone access is outside this Mac preview’s supported scope. App Store distribution is separate.
